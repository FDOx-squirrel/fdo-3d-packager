## fdo-3d-packager v1.1.0 — RO-Crate in every bundle, tidier `dist/`

- **RO-Crate and Signposting.** The pin moves to `fdo-squirrel` v1.2.1, so
  every finished bundle now contains `ro-crate-metadata.json` (RO-Crate 1.2)
  and a FAIR Signposting landing page next to the RDF metadata.
- **Tidier `dist/`.** Intermediates moved from `dist/<slug>/` and
  `dist/<slug>.zip` to `dist/_build/`, so `dist/` shows one
  `dist/<slug>_release/` per model. Inside it the finished bundle and four
  files sit on top, everything else in `_work/`. `--from`/`--skip`,
  `--all-slugs` and `--publish-only` work as before. Existing models need
  a one-off move, see "Upgrading from the old `dist/` layout" in the README.
- `dist/` is now gitignored as a whole: everything in it is rebuildable.
- The CI smoke test follows the new layout.
